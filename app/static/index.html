9-Stage Architectural Flowchart

        
Step-by-step logic pipeline mapping raw inputs into canonical entities.

        

          

            
1. Image Classifier

            
MobileNetV3 assigns CATALOG, CROP, or FULL_BODY.

          

          

            
2. Facial/Person Detection

            
OpenCV/RetinaFace + SAM isolates the garment region.

          

          

            
3. Garment Attributes

            
NVIDIA NIM VLM extracts structured attributes through 7 validation gates.

          

          

            
4. Image Digitisation

            
FLUX.2 synthesizes clean studio representation with retry loop.

          

          

            
5. Image Embedding

            
MODA SigLIP Distilled produces normalized 768d unit vector for pgvector.

          

          

            
6. Category Bundling

            
Deterministic lookup table maps subcategory to canonical category.

          

          

            
7. Layering Compatibility

            
Python decision tree validates torso layering rules.

          

          

            
8. Structural Compatibility

            
Outfit slot rules ensure anatomical slot harmony.

          

          

            
9. Visual Compatibility

            
Rules + VLM fallback calculate color and pattern harmony.

Engineering First Principles

        
Why each component was designed the way it was:

        

          

            Separate Bytes from Meaning: Binary image blobs live strictly in S3/MinIO under SHA256 hashes. PostgreSQL stores metadata, vectors, and state.
          

          

            Lookup Tables over LLMs: Category bundling uses a static versioned map. LLMs are not used for tasks deterministic dictionaries solve in microseconds.
          

          

            Normalized Embeddings: All SigLIP vectors are L2-normalized so that cosine similarity is computed in PostgreSQL via rapid dot product indexing.
