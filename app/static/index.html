Engineering First Principles

        
Why each component was designed the way it was:

        

          

            Separate Bytes from Meaning: Binary image blobs live strictly in S3/MinIO under SHA256 hashes. PostgreSQL stores metadata, vectors, and state.
          

          

            Lookup Tables over LLMs: Category bundling uses a static versioned map. LLMs are not used for tasks deterministic dictionaries solve in microseconds.
          

          

            Normalized Embeddings: All SigLIP vectors are L2-normalized so that cosine similarity is computed in PostgreSQL via rapid dot product indexing.
